# Instrucțiuni pentru rulare demo local

1. Deschide un terminal în folderul Code/
2. Exemplu (Python):
   - python -m venv .venv
   - .\.venv\Scripts\Activate
   - pip install -r requirements.txt
   - python run_demo.py
3. Dacă folosești Jupyter: rulează jupyter notebook sau jupyter lab din folderul Code/

Adaugă aici detalii specifice proiectului: dependențe, fișiere de configurare și comenzi de build/rulare.
